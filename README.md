
# Inventory Order Service - Unit Testing

## Description
This project focuses on testing an inventory order processing system using C# and xUnit. It includes tests for normal operations, boundary conditions, and exceptions.

## Tech Stack
- C#
- .NET
- xUnit
- Visual Studio
- Git and GitHub

## How to Install/Run
1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Restore NuGet packages if needed.
4. Open Test Explorer (Test > Test Explorer).
5. Click Run All to execute the unit tests.

## Features
- Happy path testing
- Edge and boundary testing
- Exception handling tests
- Inventory order validation
